# Enterprise AI CX Lab

A hands-on portfolio exploring how enterprise AI can transform customer experience by combining Salesforce, contact-center platforms, enterprise data, and generative AI.

## 🎯 Objective

My goal is to design and build enterprise-grade AI solution patterns that connect:

- Salesforce CRM
- Salesforce Data Cloud
- Agentforce
- Contact Center / Amazon Connect
- Generative AI
- Retrieval-Augmented Generation (RAG)
- Enterprise APIs and integrations
- Human-in-the-loop workflows
- AI governance and guardrails

## 🚀 Project 1: AI Customer Service Agent Assist

The first project will simulate an AI-powered customer-service environment.

The solution will analyze a customer conversation and generate structured outputs including:

- Customer intent
- Conversation summary
- Sentiment
- Recommended next-best action
- Escalation requirement
- Potential adverse-event detection
- Knowledge recommendations

Future iterations will introduce RAG, CRM customer context, tool calling, Salesforce integration, and contact-center integration.
